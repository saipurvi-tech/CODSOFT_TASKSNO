<h3>Task 3: Iris Classification Model </h3>
<b><u>Things that i have done in this project:</u></b> First I have loaded the dataset which was available on Kaggle. Then I have performed various EDA operations on the dataset, to understand it thoroughly. 
Then I have trained the model using Scikit Learn. First I have separated the feature column from the target column, and then split the dataset into the training part and the testing part. 
Then I have trained the model using the K-Nearest Neighbors algorithm which classifies based on the closest geometric neighbors. [our model is 100% accurate]
And then finally we ask the user to input the measurements and the correct prediction is displayed.
